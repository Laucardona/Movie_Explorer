instrucciones para ejecutar el proyecto
Clonar el repositorio
git clone https://github.com/tu-usuario/movie-explorer.git
cd movie-explorer
Ejecutar la aplicación

Uso

Al iniciar, se cargan automáticamente series

Usa el buscador para encontrar contenido

Navega con la paginación

Haz clic en una serie para ver detalles

Agrega favoritos

Consulta favorites.html para ver tu lista

Uso de Git

main → versión estable

develop → integración

feature/* → nuevas funcionalidades

Ejemplos de ramas:

feature/search

feature/pagination

feature/favorites

Notas

Se requiere conexión a internet

Los datos se guardan en el navegador (localStorage)

No requiere instalación de dependencias
